# הקמת הוובינר: המדריך הטכני-תפעולי

המדריך עונה על שאלה אחת: איך עוברים מ"פרסמתי פוסט בקבוצה" ל"מאות אנשים
נרשמו, קיבלו אישור ותזכורות, נכנסו לזום, ויש לי רשימת מיילים". התוכן
המקצועי של הוובינר נמצא בקבצים האחרים.

## התמונה הגדולה: איך זה זורם

```
פוסט בקבוצת פייסבוק / וואטסאפ / מודעה
                ↓  (קישור אחד)
      דף הרשמה + טופס (שם, טלפון, מייל, ✓ הסכמה לדיוור)
                ↓  אוטומטית
  ┌─────────────┼──────────────────────┐
  ↓             ↓                      ↓
רשימת תפוצה   מייל אישור מיידי        (אופציונלי) רישום בזום
(שלך, לתמיד)  + קישור לזום + "הוסף ליומן"
                ↓  אוטומטית
  תזכורות: יום לפני ← שעה לפני ← "אנחנו באוויר"
                ↓
         הוובינר בזום (מוקלט)
                ↓  אוטומטית
  מייל המשך: הקלטה + צ'קליסט + הצעה (לקורס או לשיחת ייעוץ)
```

## שלוש דרכים להקים: בחר אחת

### דרך א' — מינימלית: רק זום (חצי יום עבודה)

זום עצמו יודע לנהל הרשמה. מפעילים "Registration" בפגישה, מקבלים קישור
הרשמה ומפרסמים אותו. זום שולח לכל נרשם מייל אישור עם קישור אישי.

| יתרונות | חסרונות |
|---|---|
| הכי פשוט, בלי כלים נוספים | דף ההרשמה של זום לא מעוצב ולא ממותג |
| רשימת הנרשמים ניתנת לייצוא לאקסל | ב**פגישה** רגילה זום **לא** שולח תזכורות אוטומטיות. תזכורות אוטומטיות יש רק ברישיון Zoom Webinars |
| | אין מיילי המשך, ואין רשימת תפוצה מסודרת להמשך |

מתאים לוובינר ראשון "לבדיקת הדופק". הרשמה בזום דורשת חשבון בתשלום
(Pro ומעלה).

### דרך ב' — מומלצת: מערכת דיוור ישראלית + זום (יום-יומיים עבודה) ⭐

מערכת דיוור ישראלית עושה את כל העבודה: דף נחיתה בעברית, טופס, רשימת
תפוצה, מייל אישור, תזכורות, SMS ומיילי המשך. הדוגמאות המוכרות הן Smoove,
ActiveTrail, רב מסר ו-Responder. זום משמש **רק לשידור**: קישור הזום
(עם סיסמה) נשלח בתוך המיילים של מערכת הדיוור, ולא מפעילים בזום הרשמה.

| יתרונות | חסרונות |
|---|---|
| הכול בעברית ו-RTL, דף ממותג | מנוי חודשי למערכת הדיוור |
| **רשימת המיילים שלך** ומשמשת לכל הוובינרים הבאים | אין דוח נוכחות לפי נרשם מדויק (רק דוח משתתפים של זום לפי שם שהוקלד) |
| תזכורות ב-SMS, שמגדילות מאוד את שיעור ההגעה | |
| בלי כלי חיבור (Make/Zapier). פחות דברים שיכולים להישבר | |

### דרך ג' — מלאה: מערכת דיוור + Make/Zapier + הרשמה בזום

כמו דרך ב', ובנוסף כלי חיבור (Make או Zapier) רושם כל נרשם גם בזום. כך
כל אחד מקבל קישור אישי, ואחרי הוובינר יודעים בדיוק מי הגיע ומי לא. עם
המידע הזה אפשר לשלוח מייל שונה למי שהגיע ("תודה, הנה ההצעה") ולמי שלא
("פספסת? הנה ההקלטה").

מתאים מהוובינר השני או השלישי, כשהתהליך כבר עובד ורוצים לדייק אותו.
שווה לתת לפרילנסר אוטומציות להקים את זה (ראו "מי יכול לעשות את זה בשבילי").

## שלב אחר שלב (דרך ב')

### 1. זום (שעה)
- [ ] לשדרג לחשבון Pro
- [ ] Schedule Meeting: כותרת, תאריך, שעה, משך 75 דקות
- [ ] להפעיל סיסמה (Passcode) ו**לכבות** חדר המתנה, כדי שאנשים ייכנסו מיד
- [ ] לבחור "Mute participants upon entry"
- [ ] להפעיל הקלטה אוטומטית לענן (Automatically record → In the cloud)
- [ ] בהגדרות החשבון: רק המארח משתף מסך; להפעיל צ'אט וסקרים (Polls)
- [ ] להוסיף מנחה-משנה (Co-host) שמנהל את הצ'אט ומשתיק מפריעים
- [ ] להעתיק את קישור ההצטרפות. הוא ייכנס למיילים

### 2. מערכת הדיוור: רשימה + טופס + דף נחיתה (2–3 שעות)
- [ ] ליצור רשימה: "וובינר [שם] — [תאריך]"
- [ ] לאמת את דומיין השולח (SPF/DKIM). במערכת יש מדריך, ואיש ה-IT או ספק הדומיין מבצע ב-10 דקות
- [ ] לבנות טופס. השדות:
  - שם מלא *
  - טלפון נייד *
  - מייל *
  - תפקיד: חבר ועד / גזבר / דייר / אחר
  - מספר דירות בבניין: עד 10 / 11–30 / 31–80 / 80+
  - "מה השאלה הכי בוערת אצלכם בבניין?" (לא חובה, ונותן תוכן לוובינר)
  - ☐ **"אני מאשר/ת לקבל עדכונים ותוכן מקצועי במייל וב-SMS"**. לא מסומן מראש
- [ ] דף נחיתה עם הטקסט מ-`webinar-house-committees.md`, תמונה שלך וכפתור בולט
- [ ] עמוד תודה אחרי ההרשמה: "נרשמת! שלחנו מייל עם הקישור. הצטרף/י גם לקבוצת הוואטסאפ של הנרשמים ← [קישור]"

### 3. אוטומציות (2 שעות)
אוטומציה אחת שמופעלת בהרשמה לרשימה:

| מתי | ערוץ | מה נשלח |
|---|---|---|
| מיד בהרשמה | מייל | אישור + קישור זום + "הוסף ליומן" |
| יום לפני, 10:00 | מייל + SMS | תזכורת + קישור |
| ביום, שעה לפני | SMS | "מתחילים בעוד שעה" + קישור |
| 5 דקות אחרי ההתחלה | SMS | "אנחנו באוויר, מצטרפים כאן" + קישור |
| למחרת, 10:00 | מייל | הקלטה + צ'קליסט + הצעה |
| 3 ימים אחרי | מייל | תזכורת אחרונה להצעה |

> הקישור "הוסף ליומן" חשוב מאוד: מי ששם את הוובינר ביומן מגיע הרבה יותר.
> רוב מערכות הדיוור מייצרות אותו, ואם לא, אפשר ליצור קובץ `.ics` או
> קישור Google Calendar.

### 4. בדיקה (חצי שעה) — לא לדלג!
- [ ] להירשם בעצמך מהנייד, ממייל Gmail וממייל אחר
- [ ] לוודא שמייל האישור הגיע **לתיבה הראשית** ולא לספאם או ל"קידומי מכירות"
- [ ] ללחוץ על קישור הזום מהמייל ולוודא שהוא נכנס לפגישה הנכונה
- [ ] לבדוק שה-SMS מגיע ושהעברית לא משובשת
- [ ] לבקש מחבר להירשם ולספר מה הרגיש

### 5. פרסום (שבועיים לפני)
- [ ] **לקרוא את חוקי כל קבוצה.** הרבה קבוצות אוסרות פרסום. כדאי לפנות למנהל הקבוצה מראש, ואפשר להציע לו "וובינר בשיתוף הקבוצה"
- [ ] לא לפרסם פוסט "הירשמו!" יבש. מתחילים בערך: מפרסמים פוסט שעונה על שאלה נפוצה, ובסוף כותבים "אני מרחיב על זה בוובינר חינמי ב-[תאריך], הקישור בתגובה הראשונה"
- [ ] לתת לכל ערוץ קישור עם תיוג (UTM), למשל `?utm_source=fb_vaad_israel`, כדי לדעת מאיזו קבוצה הגיעו הנרשמים
- [ ] לפרסם מחדש בפורמט אחר 3–4 ימים לפני: שאלה מהטופס עם התשובה
- [ ] ללקוחות קיימים: הודעת וואטסאפ אישית, "תעבירו לחברים בוועד"

### 6. יום השידור
- [ ] חזרה גנרלית יום לפני עם המנחה-משנה: סאונד, שיתוף מסך, הקלטה
- [ ] להתחבר 20 דקות לפני, לפתוח את הפגישה 10 דקות לפני
- [ ] מחשב בכבל רשת, טלפון במצב טיסה, אוזניות עם מיקרופון
- [ ] קישורים מוכנים להדבקה בצ'אט: דף ההצעה, הצ'קליסט, קבוצת הוואטסאפ
- [ ] בסוף להוריד את דוח המשתתפים: Reports → Usage

### 7. אחרי
- [ ] להעלות את ההקלטה ליוטיוב כ"לא רשום" ולהכניס את הקישור למייל ההמשך
- [ ] לייצא את רשימת הנרשמים ולגבות אותה
- [ ] לרשום את המספרים: נרשמו, הגיעו, נשארו עד ההצעה, קנו או קבעו שיחה

## חוקי וחשוב

- **חוק הספאם** (חוק התקשורת, סעיף 30א): מותר לשלוח דיוור שיווקי רק למי
  שנתן הסכמה מפורשת. לכן תיבת הסימון בטופס לא מסומנת מראש, וכל מייל
  ו-SMS כולל אפשרות הסרה. מייל אישור ההרשמה עצמו הוא הודעת שירות.
- **פרטיות:** טלפונים ומיילים של נרשמים לא מעלים לקבוצה ולא משתפים. בזום
  כדאי להסתיר את רשימת המשתתפים, או לבקש מאנשים להיכנס עם שם פרטי בלבד.
- **הקלטה:** להודיע בתחילת הוובינר שהוא מוקלט. זום גם מציג הודעה כזו
  אוטומטית.

## מי יכול לעשות את זה בשבילי (מקצה לקצה)

אפשר להעביר את כל החלק הטכני לאיש מקצוע. אלה האפשרויות, מהזולה ליקרה:

1. **שירות ההטמעה של מערכת הדיוור.** חלק מהמערכות הישראליות מציעות
   הקמה מלווה או מפנות לשותפים מוסמכים. כדאי לשאול כבר בהדגמה.
2. **פרילנסר אוטומציות / משפכי שיווק.** אפשר למצוא דרך קבוצות פייסבוק
   של פרילנסרים בישראל, דרך Fiverr (לחפש "webinar funnel" או "הקמת
   משפך") או דרך מומחי Make/Zapier. זו האפשרות הנפוצה ביותר.
3. **חברת הפקת אירועים דיגיטליים.** מפיקה גם את השידור עצמו: מנחה טכני,
   גרפיקה וכמה מצלמות. יקר יותר, ולוובינר ראשון של 50–150 משתתפים
   בדרך כלל לא נחוץ.

**מה לבקש בהצעת המחיר** (מעבירים לספק כמו שזה):

> אני צריך הקמה מלאה של וובינר חינמי בזום בעברית:
> 1. דף נחיתה ממותג + טופס הרשמה (שם, טלפון, מייל, 2 שאלות סינון, הסכמה לדיוור)
> 2. רשימת תפוצה במערכת דיוור שתישאר שלי (החשבון על שמי)
> 3. מייל אישור מיידי עם קישור זום + הוספה ליומן
> 4. תזכורות: מייל + SMS יום לפני, SMS שעה לפני, SMS בתחילת השידור
> 5. מיילי המשך אחרי הוובינר (הקלטה + הצעה), אחד שונה למי שהגיע ולמי שלא (אם אפשר)
> 6. הגדרת הפגישה בזום והקלטה לענן
> 7. קישורי UTM לכל ערוץ פרסום
> 8. בדיקה מלאה לפני העלייה לאוויר + הדרכה שלי לשכפול התהליך לוובינר הבא
>
> תאריך יעד: ______. מספר נרשמים צפוי: 100–300.

**חשוב כשעובדים עם ספק:** כל החשבונות (זום, מערכת הדיוור, Make) פותחים
**על שמך ובכרטיס האשראי שלך**, ונותנים לספק הרשאה. כך הרשימה והאוטומציות
נשארות שלך גם אחרי שהעבודה איתו נגמרת.
